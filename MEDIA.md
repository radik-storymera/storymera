# Recoverable historical media

The ordinary media library shows only active files. A file referenced by the current draft, the active published revision, a story portrait, or another active media asset is protected from deletion. A file referenced only by older chapter revisions can be moved to recoverable trash: its managed ID remains stable, historical revisions can still render it, and Restore returns it to the library. Physical deletion is not exposed while any database reference remains.
