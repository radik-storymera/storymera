# Линейная глава и голосования

Сцены опубликованной версии воспроизводятся по `step`, затем по постоянному ID. Каждая сцена ведёт только к следующей. Порядок сцен в редакторе теперь определяет и порядок чтения. Варианты старых сюжетных действий и условные тексты остаются только в исторических версиях для проверки прежнего прогресса; новые голоса не создают сюжетных веток.

У сцены есть `type`: `story` или `poll`. Сюжетная сцена хранит `pollId: null` и показывает текст с медиа. Отдельная сцена `poll` обязательно ссылается через `pollId` на существующий опрос. Финальное голосование главы (`finalPollId`, тип `canonical`) показывается после завершения главы. Голосовать может только вошедший пользователь, который достиг опроса. Официальный голос один на пользователя. Повторное изменение возможно только у активного опроса с `allowVoteChange`. Пропуск не создаёт голос, сохраняется в `poll_progress` и не меняет следующую сцену; при регистрации гостевой статус переносится без повторного показа пройденного опроса.

В `/admin/polls` создаются и редактируются опросы, доступны поиск, фильтры, статистика, закрытие и архив. В редакторе сцены выбирается внутренний опрос, в свойствах главы — финальный. У каждого опроса минимум два варианта. После первого голоса существующие варианты нельзя удалить или изменить их смысл; для значительной переработки создайте новый опрос.

При закрытии сервер фиксирует число голосов и процент каждого варианта. При равенстве победитель не назначается автоматически; администратор выбирает его вручную. После публикации следующей главы финальное голосование закрывается для новых официальных голосов. Поздний читатель видит сохранённый результат. Отдельного неофициального ответа для поздних читателей пока нет. Архивирование сохраняет статистику; физическое удаление опросов через API не предусмотрено.

Миграция `005_polls.sql` добавила таблицы голосований. Позднее `server/migrate-poll-scenes.ts` создал из старой привязки опроса №1 отдельную сцену `poll-after-square` после сюжетной `square` в новой опубликованной ревизии 17 и в существующем черновике 16. Старый сюжетный текст восстановлен из ревизии 13; короткий текст более поздней poll-сцены перенесён в новую сцену. Старые публикации и прогресс на закреплённых ревизиях не переписывались. Перед применением сделана и проверена резервная копия. Скрипт сначала показывает план и при применении сверяет номера публикации, черновика и его версии редактирования.

Опросы не определяют автоматически содержание следующей главы: канонический вариант фиксирует автор. Система ключиков открывает главы, но начисление и платёжные операции пока не реализованы.
