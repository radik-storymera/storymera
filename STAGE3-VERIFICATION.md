# Этап 3 — результаты проверки 16 сентября 2026

## Реализовано

- Express 5 + TypeScript; MySQL2 и SQL-миграции с контрольными суммами и блокировкой. MySQL Community 8.4.11 LTS локально внутри проекта, без службы Windows.
- MySQL фактически запущен: миграции и интеграционные запросы выполнены, а не только обнаружен клиент.
- Пользователи, Argon2id, сессии с хешами токенов, сроком действия и отзывом; HttpOnly/SameSite cookie, Secure в production; CSRF Origin+token, лимиты входа/регистрации.
- Серверный прогресс с ID героини/главы, ревизией сценария, сценой, выборами, последовательностью действий и атомарной версией записи. Сценарий общий с клиентом.
- Гостевое чтение, компактные формы аккаунта, перенос гостевого пути, явное разрешение конфликтов, черновики отдельно по аккаунтам, сообщения об ошибке синхронизации, серверный сброс, уведомление других вкладок о выходе/смене аккаунта.
- Видео, фото, сюжет и демонстрационное продолжение сохранены. Настоящая подписка не создаётся.

## Автоматические проверки

- `npm.cmd run build` — успешно, клиент в dist.
- `npm.cmd run build:server` — успешно, сервер в server-dist.
- `npm.cmd test` — 4 теста успешны: обе ветки, объединение, восстановление, недопустимые состояния, сброс и демонстрационное продолжение.
- `npm.cmd run test:api` — 2 интеграционных сценария успешны на `jessica_stories_test`:
  - регистрация, нормализация/повтор email, валидация, неверный пароль;
  - HttpOnly cookie, получение пользователя, выход и невозможность использовать отозванную сессию;
  - CSRF без токена/с чужим Origin отклоняется;
  - чужой ID аккаунта не даёт читать или менять прогресс;
  - импорт гостевого пути, обе ветки, отклонение невозможного перехода;
  - независимый HTTP-клиент с отдельными cookie после входа восстанавливает путь;
  - устаревшая версия получает 409 с актуальным состоянием; явное разрешение конфликта и сброс работают;
  - в БД Argon2id вместо пароля; лимит авторизации возвращает 429;
  - отключённое соединение с БД возвращает безопасный 503 без SQL/секретов.
- `npm.cmd run test:secrets` — проверено отсутствие фактических сгенерированных паролей БД/root в клиентских JS/HTML/CSS/map, значения не выводились.
- HTTP 200 для сайта и /api/auth/me; HTTP 403 для /.env, /.local/mysql-root.txt, /server/db.ts.
- `npm.cmd run db:backup` — дамп основной БД создан успешно в .local/backups. Восстановление дампа не выполнялось.

## Браузер

Проверка выполнялась на изолированных портах 5175/3002 с тестовой MySQL-базой, а не с основной:

- Гость дошёл до кафе; регистрация оставила его в той же сцене, путь перенесён на сервер.
- Перезагрузка восстановила путь; после следующего перехода выход вернул отдельный гостевой путь.
- Повторный вход показал выбор между гостевым кафе и серверной площадью. После выбора восстановлен серверный путь.
- Две вкладки: после продвижения первой устаревший сброс второй открыл конфликт, не перезаписав сервер молча. Подтверждённый сброс сохранился.
- Остановлен только тестовый API: следующий переход остался на экране, статус «Not saved to server», доступен Retry sync. После возвращения API и обновления клиента локальный черновик обнаружен, предложен вместе с серверным путём и успешно сохранён по выбору.
- Смена на второй тестовый аккаунт показала начало главы, не путь первого аккаунта. Выход уведомил другую вкладку, скрыв аккаунтное состояние.
- На мобильной ширине 390×844 проверены формы/конфликт и история; горизонтального переполнения нет. Основная механика проверялась также при ширине ПК.
- Браузерные тестовые пользователи удалены только из тестовой БД по двум точным email; основная БД не очищалась. Тестовые серверы остановлены.

## Что не заявляется проверенным

- Другой физический браузер/профиль: восстановление проверено отдельным HTTP-клиентом с независимыми cookie и вкладками, без второго физического браузера.
- Production HTTPS и cookie Secure за реальным reverse proxy, нагрузочные тесты, реальный истёкший семидневный срок, физические мобильные устройства, восстановление бэкапа.
- Почта, подтверждение email, восстановление пароля, оплата и серверная защита платных медиа отсутствуют и не изображаются работающими.
